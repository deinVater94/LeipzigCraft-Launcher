# Privacy Policy

## LeipzigCraft Launcher

The LeipzigCraft Launcher is an open-source launcher for the LeipzigCraft Minecraft server.

The launcher does not intentionally collect analytics, advertising identifiers, telemetry, or unrelated personal information for LeipzigCraft.

## Network connections

To provide the functionality requested by the user, the launcher may connect to the following systems:

### Microsoft / Xbox / Minecraft services
Used for Microsoft account authentication, Minecraft ownership/session authentication, and downloading official Minecraft files required to run the game.

### Mojang / Minecraft distribution services
Used to obtain official Minecraft 1.21 game files, assets, libraries and the required runtime where applicable.

### Fabric services
Used to obtain metadata and files required for Fabric Loader 0.17.3.

### leipzigcraft.com
Used to retrieve the signed LeipzigCraft pack manifest and detached signature:
- `/launcher/pack.json`
- `/launcher/pack.sig`

### GitHub
Used to download LeipzigCraft modpack files and configuration archives from official LeipzigCraft GitHub Releases.

## Local data

The launcher stores its game installation and launcher state under:

`%APPDATA%\LeipzigCraft`

This may include Minecraft game files, Fabric files, LeipzigCraft mods/configuration, launcher update state, locally cached authentication/account data, the running game process ID and Minecraft's local multiplayer server list.

The launcher does not intentionally upload these local files to LeipzigCraft.

## LeipzigCraft game server

When the player chooses to connect to the LeipzigCraft Minecraft server, Minecraft communicates directly with:

`185.9.104.131:10100`

Server-side processing and logging associated with gameplay are separate from the launcher's local update functionality.

## Third-party services

Microsoft, Minecraft/Mojang, GitHub and Fabric services are operated by their respective organizations and are subject to their own privacy policies and terms.
