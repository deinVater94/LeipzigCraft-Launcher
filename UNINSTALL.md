# Uninstalling LeipzigCraft Launcher

The LeipzigCraft Launcher is distributed as a portable/self-contained Windows application and does not require a traditional system-wide installer.

To remove it:

1. Close Minecraft and the LeipzigCraft Launcher.
2. Delete the `LeipzigCraft-Launcher.exe` file wherever you saved it.
3. Press `Win + R`.
4. Enter `%APPDATA%`.
5. Delete the folder `LeipzigCraft`.

Deleting `%APPDATA%\LeipzigCraft` removes the separate LeipzigCraft Minecraft installation, downloaded mods, configuration, launcher state and locally cached launcher/account data stored there.

The launcher does not intentionally modify or delete the user's normal `%APPDATA%\.minecraft` installation during uninstallation.
